# Assignment 2-3: 동시 접속 FTP 명령 서버

앞선 FTP 명령 변환·처리에 소켓 통신과 `fork()`를 결합한 과제이다. 서버는 클라이언트마다 자식 프로세스를 만들어 명령을 처리한다.

## 주요 내용

- `ls`, `dir`, `pwd`, `cd`, `mkdir`, `delete`, `rmdir`, `rename`, `quit`을 FTP 명령으로 변환한다.
- 서버가 다중 접속을 처리하고 클라이언트의 PID, 포트, 접속 시간을 출력한다.
- `SIGCHLD`, `SIGALRM`, `SIGINT`를 이용해 자식 프로세스와 종료를 관리한다.

## 빌드와 실행

```bash
make
./srv 5000
```

다른 터미널에서 클라이언트를 실행한다. 여러 터미널에서 각각 접속할 수 있다.

```bash
./cli 127.0.0.1 5000
```
