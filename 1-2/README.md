# Assignment 1-2: 디렉터리 목록 조회

`opendir()`, `readdir()`, `closedir()`를 이용해 지정한 디렉터리의 항목 이름을 출력한다. 경로를 생략하면 현재 디렉터리를 조회하며, 경로를 여러 개 입력하거나 접근에 실패한 경우 오류를 출력한다.

## 빌드와 실행

Linux 환경에서 GCC를 사용한다. 현재 폴더에 Makefile이 없어 직접 컴파일한다.

```bash
gcc -Wall -o kw2022202078_ls kw2022202078_ls.c
./kw2022202078_ls
./kw2022202078_ls /tmp
```

이 단계는 항목 이름을 출력하는 연습으로, `ls`의 모든 옵션을 구현하지는 않는다.
