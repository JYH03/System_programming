# Assignment 2-2: fork 기반 에코 서버

`fork()`로 클라이언트마다 자식 프로세스를 생성하는 TCP 에코 서버이다. 클라이언트가 보낸 문자열을 서버가 그대로 돌려주며, 부모 프로세스는 다음 연결을 기다린다.

## 주요 내용

- 접속 시 클라이언트 정보와 프로세스 정보를 출력한다.
- `QUIT`을 받으면 해당 연결을 종료하며, `SIGALRM`과 `SIGCHLD` 처리를 연습한다.

## 빌드와 실행

```bash
make
./srv 5000
```

다른 터미널에서 클라이언트를 실행한 뒤 문자열을 입력한다. 종료할 때는 `QUIT`을 입력한다.

```bash
./cli 127.0.0.1 5000
```
