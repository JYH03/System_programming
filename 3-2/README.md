# Assignment 3-2: FTP 제어 연결과 데이터 연결

FTP의 제어 연결과 별도의 데이터 연결을 구성해 디렉터리 목록을 전송한다. 클라이언트는 `PORT` 명령으로 데이터 연결 주소와 포트를 알리고, 서버는 해당 주소로 연결해 `NLST` 결과를 보낸다.

## 빌드와 실행

```bash
make
./srv 5000
```

다른 터미널에서 접속한 후 `ls`를 입력한다.

```bash
./cli 127.0.0.1 5000
```

클라이언트는 데이터 연결에 10001~30000 범위의 포트를 선택한다. 제어 연결의 응답과 데이터 연결의 목록 전송을 함께 확인할 수 있다.
