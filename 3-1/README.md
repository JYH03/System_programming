# Assignment 3-1: 클라이언트 접근 및 로그인 인증

서버 접속 시 IP 허용 여부를 확인하고, 사용자 이름과 비밀번호를 검사하는 인증 과제이다. 로그인에 세 번 실패하면 연결을 종료한다.

## 빌드와 실행

서버 실행 디렉터리에 `access.txt`와 `passwd`가 포함되어 있다. `access.txt`에 등록된 IP 또는 와일드카드 패턴과 일치하는 IP만 접속할 수 있으며, `passwd`에 등록된 사용자 이름과 비밀번호가 일치해야 로그인할 수 있다.

```bash
make
./srv 5000
```

다른 터미널에서 접속한다.

```bash
./cli 127.0.0.1 5000
```

접속이 허용되면 `passwd`에 등록된 사용자 이름과 비밀번호를 입력한다.
