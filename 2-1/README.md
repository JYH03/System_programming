# Assignment 2-1: 기본 소켓 통신

TCP 소켓으로 클라이언트와 서버를 연결한다. 클라이언트는 `ls`와 `quit`을 `NLST`와 `QUIT`으로 변환해 전송하고, 서버는 명령을 처리해 결과를 돌려준다. `ls`의 `-a`, `-l` 옵션을 다룬다.

## 빌드와 실행

Linux에서 `make`로 빌드한 후 터미널 두 개를 사용한다.

```bash
# 서버
./srv 5000

# 다른 터미널에서 클라이언트
./cli 127.0.0.1 5000
```

클라이언트에서 `ls`, `ls -al`, `quit` 등을 입력한다. 서버는 접속한 클라이언트의 IP와 포트를 출력한다.
